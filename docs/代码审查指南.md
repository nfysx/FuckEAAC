# FuckEAAC —— 代码审查指南

> ← 返回 [README](../README.md)　｜　其他文档：[编译与改代码.md](编译与改代码.md) · [Rust-入门与代码导读.md](Rust-入门与代码导读.md)

这份文档是给"想确认这个 exe 到底干了什么"的人看的（包括你自己、以及任何质疑它的人）。
所有结论都给出**可复现的命令**，你不需要相信我，跑一遍即可。

版本：v2.0.0（Tauri + Rust 后端 / HTML+JS 前端）
结论先行：**它只做两件事 —— 停掉你自己的代理工具、之后恢复它们。不联网、不碰反作弊、不上报。**

## 2. 它执行的全部外部命令（含参数）

`actions.rs`（唯一会改系统的文件）：

| 行 | 命令 | 说明 |
|---|---|---|
| 109 | `taskkill.exe /IM <名>.exe /F` | 结束代理客户端 |
| 136 | `sc.exe stop <服务名>` | 停服务/内核驱动 |
| 151 | `sc.exe config <服务名> start= demand` | 可选：改成按需加载 |
| 237 | `sc.exe start <服务名>` | 恢复时启动 |
| 258 | `sc.exe config <服务名> start= auto\|demand\|...` | 恢复原始启动类型 |
| 311 | `explorer.exe <客户端路径>` | 恢复时以**普通用户身份**代开代理客户端（失败才直接启动） |
| 336 | `sc.exe qc <服务名>` | 读原始启动类型（只读） |

`actions.rs` 还会用 **PowerShell** 写一次**系统代理设置**（见下面的"可写清单"）：

```powershell
# 关掉：ProxyEnable=0，并清空 AutoConfigURL（PAC）
# 恢复：把 state.json 里记下的 ProxyEnable / ProxyServer / AutoConfigURL 写回去
Set-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings' ...
[InternetSetOption](...)  # 通知 WinINet 立刻生效，否则已打开的浏览器还用旧设置
```

`detect.rs`（只读）：`sc.exe query type= service|driver state= all`、`sc.exe query <名>`、
`tasklist.exe /fo csv /nh`、`netsh.exe interface show interface`（网卡兜底）、
PowerShell（网卡/系统代理查询）。

`util.rs`：`net.exe session`（判管理员，只读）、`tasklist.exe /FI "IMAGENAME eq ..."`（数进程）、
`explorer.exe <路径>`（以普通用户身份代开客户端）、`powershell.exe`（仅在 tasklist 不可用时兜底）。

**只读 vs 可写**：`detect.rs`、`diag.rs`、`state.rs` 不做任何修改系统的动作；
真正改系统的只有 `actions.rs`，一共四件事：

1. **结束进程**（`taskkill`）
2. **停服务/驱动**（`sc stop`）
3. **改服务启动类型**（`sc config ... start= demand`，恢复时改回去）
4. **关掉 Windows 系统代理**（写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings`
   下的 `ProxyEnable` / `ProxyServer` / `AutoConfigURL` 三个值；原值记进 `state.json`，恢复时写回）

第 4 项**可以在配置里关掉**：`"DisableSystemProxy": false`。
另外程序**从不**碰注册表的任何其它位置 —— 没有 IFEO、没有反作弊相关键、没有驱动安装。

`util.rs` 里所有外部命令都有 **20 秒超时**（`CMD_TIMEOUT_SECS`）：卡住的命令会被强制结束并记进日志，
不会把界面拖死。

## 3. 怎么确认"没有绕过反作弊"

反作弊绕过通常长这样，本工程里**一条都没有**（第 0 节的第 4 条命令可以直接跑出来）：

| 绕过手法 | 本工程 |
|---|---|
| IFEO 映像劫持（`Debugger=` 指向别的 exe） | ✗ 无。没有 `reg.exe`、没有 `Image File Execution`、没有反作弊相关注册表键 |
| 进程注入 / 远程线程 / 挂钩子 | ✗ 无 `OpenProcess`/`WriteProcessMemory`/`CreateRemoteThread`/`SetWindowsHookEx` |
| 改进程/线程优先级（把反作弊调到最低） | ✗ 无 `SetPriorityClass`/`SetThreadPriority` |
| 加载/卸载内核驱动（`NtLoadDriver`、`sc create`） | ✗ 无。只会 `sc stop/start` **已经存在的、你自己的** 代理驱动 |
| 伪造签名 / 篡改文件 / patch exe | ✗ 无任何文件写操作落到游戏或反作弊目录 |
| 屏蔽反作弊进程/服务 | ✗ 无。目标清单里的东西分三类：①**代理/网络类软件**（Proxifier、Clash/mihomo、ProxyCap、SocksCap…）②**抓包/变声/调试类**工具 ③**别的游戏平台的反作弊**（腾讯 ACE、完美平台，**均为 `Action: Hint` —— 需你手动处理**：正在运行时只把它们标进「需停用」栏并提示你自己关闭/重启，**程序不会 taskkill、不会 sc stop**）。**EAAC/EAC 自己（EAAntiCheat、EasyAntiCheat）不在清单里，程序从不碰它们。** |

> 唯一的注册表写入是 **用户级代理设置**（`HKCU\...\Internet Settings` 的 3 个值），
> 目的是"把你自己的系统代理开关也关掉"，跟反作弊没有任何关系，而且原值可还原、可在配置里禁用。

它做的恰恰是**相反方向**的事：**把本机的代理工具关干净**，让 EAAC 看到的环境是干净的。
换句话说，它是"配合反作弊"的工具，不是"对抗反作弊"的工具。

设计上唯一和游戏有关的部分是 `play.rs`：**每 5/10 秒用 `tasklist` 看游戏进程还在不在**。
不注入、不读内存、不挂钩子 —— 就是看进程列表。

## 4. 怎么确认"不联网、不上报"

**证据一：源码里没有任何网络 API。**
第 0 节第 3 条命令（`fetch(` / `XMLHttpRequest` / `WebSocket` / `http://` / `https://`）跑出来是空的。
前端是纯静态 HTML+JS，连第三方 JS 库都没有，不存在 CDN 请求。

**证据二：没有 HTTP 客户端库被链接进来。**

```powershell
cargo tree -i reqwest     # nothing to print
cargo tree -i hyper       # nothing to print
```

`Cargo.lock` 里确实出现过 `reqwest` / `hyper` —— 那是 **Tauri 为其它平台/可选特性登记的**，
本机 `windows-msvc` + 当前特性集下不在依赖图里（`--target all` 才看得到它挂在 `tauri` 下面）。
直接查二进制更实在：

```powershell
$exe = 'src-tauri\target\release\fuckeaac.exe'
$t = [Text.Encoding]::ASCII.GetString([IO.File]::ReadAllBytes($exe))
'reqwest','hyper::','rustls','h2::','WinHttp','curl_easy' | % { "$_ : " + $t.Contains($_) }
# 期望：全部 False
```

**证据三：直接依赖只有 4 个**（`cargo tree --depth 1`）：
`tauri`、`tauri-plugin-dialog`、`serde`、`serde_json`。没有 HTTP、没有遥测、没有统计 SDK。

```powershell
cargo tree --depth 1
```

**注意一个诚实的例外**：界面是用**系统自带的 WebView2（Edge/Chromium）**渲染的。
WebView2 运行时是 Microsoft 的组件，它自己可能会做 SmartScreen/证书之类的网络查询 ——
那是**浏览器的行为，不是本程序的行为**，本程序没有向它传入任何网址，也没有调用它的任何网络 API。
（exe 里能搜到 `http://` 字样，来自 Tauri 内嵌资源的 `tauri://localhost` 协议名
和 WebView2 SDK 里的 Chromium 命令行开关表；`analytics` 这个词来自 `brotli` 压缩字典的
英文词表 —— 都是字符串常量，不是代码路径。可以自己解压/搜索核对。）

## 7. 已知边界（不藏着）

1. **它停的是"服务/驱动/进程/系统代理开关"，不是"网络行为"**。停完之后你自己把 Proxifier 再打开，它不会拦你。
2. **重复停用/恢复同一批服务会有副作用**：某些驱动不支持热卸载，停用后需要重启才彻底生效
   —— 日志里会明确写出来。
3. **`tasklist` 被安全软件挡住时，"等待游戏"不可靠**，所以开始等待前会先自检；
   查不到进程列表就直接拒绝，而不是假装在等。
4. **强杀程序时不会自动恢复**（后台线程随进程消失）—— 但 `state.json` 还在，
   下次打开会提示"上次停了 N 项"，点「恢复代理工具」即可。
5. **系统代理这一步是可逆的，但要留意两种情况**：
   - 关掉时若写注册表失败，程序**不会**记原值（避免恢复时乱写），日志里会有 ✗，你需要手动去
     「设置 → 网络和 Internet → 代理」处理；
   - 恢复时会把 `ProxyEnable` 写回 **1**（如果你原来是开着的）。如果你的代理客户端里
     「系统代理」开关本身是关的，记得再手动关一下，否则流量会指向它。
   不想要这个行为：配置里 `"DisableSystemProxy": false`。
6. **封号风险**：本工具让 EAAC 更容易通过，但**不保证**不被封；在游戏里使用网络工具的
   ToS 风险始终由使用者承担。
